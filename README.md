# Lumen Camera

A pro camera web app with an iPhone-style interface.

- Lens picker with live previews of every camera on the phone
- Modes: Time-lapse, Slo-mo, Video, Photo, Portrait 1:1, Pro
- Manual ISO, shutter, EV, white balance and focus (Android Chrome)
- Live histogram, zebra, focus peaking, grid and level
- Night stacking, burst, timer, styles, 4K and 60 fps video

## Use

Open the GitHub Pages link of this repository on your phone and tap Open camera.
The camera only works over https, which GitHub Pages provides.
